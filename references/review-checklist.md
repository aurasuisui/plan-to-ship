# 审核清单(逐条给命令)

| # | 查什么 | 命令 | 通过标准 |
|---|---|---|---|
| 1 | diff 边界 | `git diff --stat <base>..HEAD` | 只含授权文件 |
| 2 | 测试是否被削弱 | `git diff <base>..HEAD -- '*test*'` | 只增不减,断言未放宽 |
| 3 | 数字能否推出 | 按仓库里的基准表重算 | 与报告一致 |
| 4 | 台账/看板是否被动 | `git diff -- <plan/contract file>` | 审核者之外无人改 |
| 5 | 自己造一次证据 | 复跑测试 / 自己打包 / 自写探针 | 结果与报告一致 |
| 6 | 环境事实 | 版本、编码、路径先验证 | grep 类门禁不假绿 |
| 7 | 不可逆前置 | 工作树干净、远端一致、目标不存在 | 四行确认写给你 |
| 8 | 偏差是否显式 | 报告里的「偏离」小节 | 有,且解释合理 |

## 判分写法

```
判定:通过 / 驳回
依据:① <命令> exit 0 ② <计数> = <值> ③ diff 仅 <文件>
驳回理由(如驳回):<具体差异> + <复跑命令>
```

**不接受**:"基本完成"、"看起来没问题"、"应该可以"。
